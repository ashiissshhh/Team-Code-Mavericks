## 📌 Project Overview
Placement Practice Planner is a Streamlit-based web application designed to help students optimize their placement preparation. It automatically prioritizes study topics based on accuracy rates and recency of practice, ensuring students focus on their weakest areas first.

---

## ✨ Key Features
- ➕ **Add/Edit/Delete Topics:** Full CRUD functionality for practice topics.
- 📊 **Accuracy Tracking:** Calculates topic accuracy dynamically (`(Correct Answers / Questions Tried) * 100`).
- 🔴 **Smart Priority Engine:** Assigns High, Medium, or Low priority based on low accuracy or outdated practice.
- 💡 **Explanation Engine:** Gives clear reasons why a topic holds a specific priority.
- 🎯 **Pre-loaded Sample Data:** Includes initial topics for instant testing.
